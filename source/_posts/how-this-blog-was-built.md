记录一下这个小站的技术选型，给以后的自己留个档，也给想搭同款的人一个参考。

## 技术栈

| 部分 | 选择 | 理由 |
| ---- | ---- | ---- |
| 生成器 | Hexo 7 | 中文生态成熟，Markdown 写作，插件齐全 |
| 主题 | 自研 retro-desktop | 想要的 Win98 复古桌面风没有现成的 |
| 评论 | Giscus | 基于 GitHub Discussions，免费无广告 |
| 订阅 | Atom (hexo-generator-feed) | 标配 |
| 搜索 | hexo-generator-search | 纯前端，免服务端 |
| 部署 | 自有服务器 | 自己的域名自己的机器，自由 |

## 主题里比较有意思的细节

- **斜面边框**：没有用任何 UI 库，全部手写 `box-shadow` 四层嵌套模拟 Win98 的凸起/凹陷效果
- **任务栏**：页面底部固定一条任务栏，左边的「开始」按钮回首页，右边的时钟每秒跳一次
- **搜索**：`Ctrl/⌘ + K` 唤起弹窗，前端直接搜 `search.json`，带关键词高亮
- **像素装饰**：✦ ✧ ❤ 这些字符装饰 + `image-rendering: pixelated` 的头像框
